# 03 Console Commands Cheat Sheet

- stat fps: Shows frame rate and execution time.
- stat unit: Displays Frame, Game thread, Draw thread, GPU thread time.
- 
.Nanite 0/1: Toggle Nanite globally.
- 
.Lumen.DiffuseIndirect.Allow 0/1: Toggle Lumen GI.
- profilegpu: Captures GPU frame pass details.
