# Master Material Node Encyclopedia

## 1. Texture Sample
Inputs: UVs. Outputs: RGB, R, G, B, Alpha. Samples 2D texture maps.

## 2. Panner
Inputs: Coordinate, Time, Speed (X, Y). Moves UV coordinates dynamically over time.

## 3. Fresnel
Inputs: Exponent, Normal. Generates rim lighting effect based on camera angle relative to surface normal.

## 4. Depth Fade
Inputs: Inverted, Fade Distance. Blends translucent surfaces smoothly into geometry background to prevent sharp clipping.
